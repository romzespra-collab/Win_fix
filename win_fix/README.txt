ЧТО ДЕЛАЕТ
──────────
Чинит Windows после «сборок»:
 🖱 Курсор        — вернуть стандартный, размер 1–15, вернуть оригинальные файлы из WinSxS,
                    удалить авторские схемы.
 🔊 Звуки входа   — сброс звуков событий, мелодия запуска вкл/выкл.
 🚀 Автозагрузка  — реестр Run/RunOnce/Policies, папки, Планировщик, службы, Active Setup;
                    🎵 — музыка/плееры.
                    Отключить (обратимо, как в диспетчере задач) / удалить.
 🗑 Программы    — удаление программы её деинсталлятором + поиск и удаление остатков
                    (папки, реестр, ярлыки, службы, задачи); файлы — в backup\uninstall.
 🩺 Реестр        — Shell/Userinit, запреты (диспетчер, regedit, cmd), IFEO,
                    AppInit, ассоциация .exe, UAC, обновления, Defender, прокси, hosts.
 🔌 Порты         — netstat + процессы, рискованные порты, блок в брандмауэре.
 🧽 Чистка       — чистка реестра как в CCleaner (10 категорий), флешки/сеть не трогает, откат.
 ⚙ Службы        — отключённые сборкой службы (звук, поиск, сеть, защита) → по умолчанию.
 🧭 Браузеры      — ярлыки браузеров с сайтом, политики стартовой/поиска/расширений.
 📋 Меню          — пункты контекстного меню Проводника: скрыть / показать / удалить.
 🏴 Активаторы    — следы KMSAuto/AAct/KMSpico: задачи, службы, файлы, IFEO, исключения Defender.
 🌐 Сеть          — проверка DNS, сброс DNS / Winsock / TCP-IP / прокси WinHTTP.
 🛠 Система       — 🪄 Исправить всё, 📄 Отчёт, DISM + SFC (⏹ остановить), точка восстановления,
                    стандартная тема/обои, OEM-сведения, ссылки на WinUtil, Sophia Script, Autoruns, TCPView.
 ↩ Откат          — журнал всех изменений (backup\undo_*.json), откат одной кнопкой.
Слева — панель вкладок (☰ свернуть). Правый клик по таблицам, логу и панели — меню.

СТРУКТУРА
─────────
 win_fix.py       — вся программа
 win_fix.pyw      — запуск двойным кликом
 win_fix.spec     — сборка EXE
 build_exe.bat    — сборка одним кликом
 requirements.txt
 logs\win_fix.log — подробный лог (создаётся сам; его и присылать при ошибках)
 backup\          — журнал отката (создаётся сам)
 reports\         — отчёты 📄
