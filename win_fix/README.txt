WinFix  v1.3.2
══════════════════════════════════════════════

ЧТО ДЕЛАЕТ
──────────
Чинит Windows после «сборок»:
 🖱 Курсор        — вернуть стандартный, размер 1–15, вернуть оригинальные файлы из WinSxS,
                    удалить авторские схемы.
 🔊 Звуки входа   — сброс звуков событий, мелодия запуска вкл/выкл.
 🚀 Автозагрузка  — реестр Run/RunOnce, папки, Планировщик; 🎵 — музыка/плееры.
                    Отключить (обратимо, как в диспетчере задач) / удалить.
 🩺 Реестр        — Shell/Userinit, запреты (диспетчер, regedit, cmd), IFEO,
                    AppInit, ассоциация .exe, UAC, обновления, Defender, прокси, hosts.
 🌐 Порты         — netstat + процессы, рискованные порты, блок в брандмауэре.
 🛠 Система       — DISM + SFC, точка восстановления, ссылки на WinUtil,
                    Sophia Script, Autoruns, TCPView.
Слева — панель вкладок (☰ свернуть). Правый клик по таблицам, логу и панели — меню.

СТРУКТУРА
─────────
 win_fix.py       — вся программа
 win_fix.pyw      — запуск двойным кликом
 win_fix.spec     — сборка EXE
 build_exe.bat    — сборка одним кликом
 requirements.txt
 logs\win_fix.log — подробный лог (создаётся сам; его и присылать при ошибках)

ЗАПУСК
──────
Двойной клик по win_fix.pyw — библиотеки поставятся сами,
программа попросит права администратора.
Совет: сначала 🛠 → «💾 Точка восстановления».

СБОРКА В EXE
────────────
Запустить build_exe.bat → dist\win_fix.exe
